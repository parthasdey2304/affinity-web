## Themes

Affinity comes with beautiful built-in themes.

- Monokai
- Dracula
- One Dark
- Nord
- Solarized

```bash
$ affinity main.py --theme dracula
[Affinity] Loading 'dracula' theme...
[Affinity] Rendering main.py

def welcome():
    print("Welcome to the Dark Side.")

[Affinity] Render complete.
```
