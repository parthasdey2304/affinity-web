## Diff Viewer

Affinity includes a built-in diff viewer.

```bash
$ affinity old.py new.py --diff
[Affinity] Generating diff for old.py and new.py...

- def calculate_total(amount):
-     return amount * 1.1
+ def calculate_total(amount, tax_rate=0.1):
+     return amount * (1 + tax_rate)

[Affinity] 2 lines removed, 2 lines added.
```
