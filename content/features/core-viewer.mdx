## Core Viewer

The core viewer of Affinity replaces standard `cat` or `bat` with a fully featured syntax highlighter powered by Pygments.

Features include:
- Scope guides
- Dynamic file headers
- Smart line wrapping

```bash
$ affinity main.py
[Affinity] Rendering main.py

import json
import sys

def main():
    print("Welcome to Affinity Viewer!")
    
if __name__ == "__main__":
    main()

[Affinity] Render complete in 0.04s.
```
