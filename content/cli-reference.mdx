## CLI Reference

Here is the full list of CLI commands available:

```bash
$ affinity --help
Usage: affinity [OPTIONS] [FILE]

  Affinity - A beautiful IDE-like terminal viewer.

Options:
  --watch         Live reload on file save
  --run           Execute the script and view output
  --diff FILE     Compare two files
  --tree          Show directory tree
  --focus LINES   Focus on specific lines (e.g., 10-20)
  --mirage        Enable Mirage mode (Beta)
  --theme NAME    Select syntax highlighting theme
  --help          Show this message and exit.
```
